# 🚀 JanSetu — Smart Civic Complaint Management System

JanSetu is a multilingual civic grievance platform designed to simplify public issue reporting and municipal workflow management.

The platform enables citizens to report problems like potholes, water leakage, garbage overflow, and electricity issues in just a few taps — without requiring citizen login.

---

# 🌟 Key Features

## 👥 Citizen Side (No Login Required)
- Instant complaint reporting
- Visual-first interface for low-literacy users
- Multilingual support:
  - English
  - Hindi
  - Telugu
  - Urdu
- Upload issue photos
- Complaint tracking using unique complaint ID
- Mobile-friendly responsive UI

---

## 🧑‍💼 Officer Dashboard
- Secure officer/admin workflow
- Complaint lifecycle management:
  - Assigned
  - Started
  - Resolved
  - Escalated
- One-tap work initiation
- Proof-based resolution system
- Mandatory before/after work image uploads
- Live task queue and workload monitoring

---

# 🧠 Problem Statement

Traditional civic complaint systems are often:
- complicated
- inaccessible
- language-restricted
- difficult for rural or low-literacy citizens

JanSetu solves this through:

- multilingual accessibility
- simplified visual UI
- efficient officer workflow management
